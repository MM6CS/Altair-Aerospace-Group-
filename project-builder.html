Review your project entry, then download the updated catalogue and replace projects-data.js with it. Copy any new files into the matching project folder before publishing.

Open file guide ↗

  1. Create project-files/<division>/<project-id>/.
  2. Copy the selected deliverables there; keep related files organised in folders such as documents/, cad/, models/ and results/.
  3. Check you have permission to publish every file; remove secrets and sensitive or controlled technical data.
  4. Commit the files and project entry to your GitHub repository. The public listing updates when GitHub Pages deploys.
